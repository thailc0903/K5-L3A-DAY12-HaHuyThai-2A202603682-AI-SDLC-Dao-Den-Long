# Đảo Đèn Lồng v1.0.0

Game3D qua ba Đêm, giữ đảo sáng tới bình minh. Contract1.3, đầy đủ các luật Phase1–3, benchmark/soak, bảng xếp hạng lưu đĩa, đổi phím và accessibility Phase4.

## Chạy bản ZIP

1. Cài Node.js20+ và trình duyệt WebGL2 (Chrome/Edge cho benchmark).
2. Tải dao-den-long-v1.0.0.zip, giải nén, mở terminal trong thư mục dao-den-long.
3. Chạy `node scripts/serve.mjs`, mở http://127.0.0.1:4173.

Không cần npm install hoặc Internet sau khi tải. START-HERE.txt và [hướng dẫn sản phẩm](https://github.com/thailc0903/K5-L3A-DAY12-HaHuyThai-2A202603682-AI-SDLC-Dao-Den-Long/blob/v1.0.0/docs/game/README.md) có điều khiển/test/headless/bench/soak. README lab gốc giữ nguyên theo yêu cầu người học.

## Tệp đính kèm

- ZIP ứng dụng + SHA256SUMS.txt.
- demo.mp4: người học chơi trực tiếp, dưới5phút; video canvas/HUD, không có âm thanh hoặc desktop.
- bench.json và soak.json: output thật; cấu hình/hash/ngữ cảnh trong docs/proof/phase-4/ của source/ZIP.

## Kiểm chứng và giới hạn

79 test,18 scenario, fixture thắng ba Đêm,24 output JSONL giống Phase3 từng byte, clone/bản giải nén kiểm tra lại. Benchmark chuẩn200shades/100motes/3đèn, warmup3s+30s đo; soak10Đêm một tiến trình0crash và RSS trong ngưỡng20%. Số đo GPU là tham khảo máy Windows hiện tại; giảng viên đo lại trên máy chấm.

Web vsync_off=false, peak_mem_mb=null: trình duyệt không có API chuẩn tắt vsync/đọc RSS renderer tin cậy. Cấu hình soak_cmd có --jitless, --expose-gc, --max-semi-space-size=1 để ổn định memory runtime, được công khai trong contract. Chưa review bằng mắt mọi menu/settings/âm thanh hoặc macOS; không tuyên bố chạy được mọi test ẩn chưa được cung cấp.
